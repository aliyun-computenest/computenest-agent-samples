# AgentScope 示例集合

本仓库收录基于 [AgentScope](https://doc.agentscope.io/) 的示例应用（**AgentScope 2.0** / Agent Service）。

| 目录 | 说明 |
|------|------|
| `conversation/` | 对话示例（Agent Service + 可选 MCP） |
| `travel_planner/` | 智能旅行规划（Skill 知识库 + 高德 MCP） |
| `stock_analyst/` | 股票分析助手（百炼 WebSearch MCP；**非持牌投顾**） |
| `opinion_analyst/` | 舆情 Deep Research（百炼 WebSearch MCP） |
| `dashscope_memory/` | DashScope 长期记忆 + Runtime Session |
| `knowledge_rag/` | 企业知识库智能问答（百炼 RAG） |
| `browser_use/` | 智能浏览器操控（Playwright MCP + 云端沙箱） |
| `agent_research/` | AI 搜学助手（Playwright + 可视化报告） |

各子目录独立运行，详见对应 `README.md`。
