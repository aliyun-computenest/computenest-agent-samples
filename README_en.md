# AgentScope Sample Collection

Sample applications built on [AgentScope](https://doc.agentscope.io/) (**AgentScope 2.0** / Agent Service).

| Directory | Description |
|-----------|-------------|
| `conversation/` | Conversation demo (Agent Service + optional MCP) |
| `travel_planner/` | Travel planner (Skill knowledge + Amap MCP) |
| `stock_analyst/` | Stock analysis assistant (DashScope WebSearch MCP; **not licensed investment advice**) |
| `opinion_analyst/` | Opinion / sentiment Deep Research (DashScope WebSearch MCP) |
| `dashscope_memory/` | DashScope long-term memory + Runtime Session |
| `knowledge_rag/` | Enterprise knowledge-base QA (DashScope RAG) |
| `browser_use/` | Browser automation (Playwright MCP + cloud sandbox) |
| `agent_research/` | AI research assistant (Playwright + visual report) |

Each subfolder runs independently; see its own `README.md` for instructions.
