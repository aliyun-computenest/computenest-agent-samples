# AgentScope Samples (English)

This repository collects sample applications built with [AgentScope](https://doc.agentscope.io/) and [AgentScope Runtime](https://runtime.agentscope.io/). Chinese documentation lives in each folder’s `README.md`; **English documentation is in `README_en.md` inside each sample directory** (samples below).

| Sample | English README |
|--------|----------------|
| Conversation (minimal chat) | [conversation/README_en.md](conversation/README_en.md) |
| Intelligent travel planner | [travel_planner/README_en.md](travel_planner/README_en.md) |
| Stock analysis assistant | [stock_analyst/README_en.md](stock_analyst/README_en.md) |
| Opinion deep research | [opinion_analyst/README_en.md](opinion_analyst/README_en.md) |
| DashScope long-term memory | [dashscope_memory/README_en.md](dashscope_memory/README_en.md) |
| Enterprise knowledge base Q&A | [knowledge_rag/README_en.md](knowledge_rag/README_en.md) |
| Browser use assistant | [browser_use/README_en.md](browser_use/README_en.md) |
| AI study research assistant | [agent_research/README_en.md](agent_research/README_en.md) |

Each subdirectory runs on its own (`cd <dir>` → install deps → configure env → `python main.py`).
